# 🛳️ Hundir la Flota

Proyecto en Python que recrea el clásico juego de "Hundir la flota", donde el jugador compite contra la máquina.

---

## 🎮 ¿Cómo funciona?

* Los barcos se colocan aleatoriamente en el tablero respetando los límites
* El jugador introduce coordenadas para atacar
* La máquina responde con sus propios ataques
* Se muestran aciertos (💥) y fallos (🌊)
* Gana quien hunda todos los barcos del rival

---

## 🧠 Conocimientos empleados

* Uso de listas y matrices
* Lógica de juego por turnos
* Control de flujo (if, loops)
* Organización del código en Python

---

## ⚙️ Cómo ejecutar el proyecto

1. Clona el repositorio:

```bash
git clone https://github.com/naiamerino/THE_BRIDGE-Data-Science-Projects.git
```

2. Entra en la carpeta del proyecto:

```bash
cd THE_BRIDGE-Data-Science-Projects/Hundir-la-flota
```

3. Ejecuta el juego:

```bash
python main.py
```
