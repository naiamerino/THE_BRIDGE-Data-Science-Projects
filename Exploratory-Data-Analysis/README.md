# 📊 Exploratory Data Analysis (EDA) Project

## 🧾 Descripción

Este proyecto consiste en un **análisis exploratorio de datos (EDA)** cuyo objetivo es comprender en profundidad un dataset, identificar patrones, detectar anomalías y extraer conclusiones relevantes.

---

## 🎯 Objetivos

* Entender la estructura del dataset
* Limpiar y preparar los datos
* Analizar variables individuales y relaciones entre ellas
* Generar visualizaciones claras e informativas
* Extraer insights útiles

---

## 🛠️ Tecnologías utilizadas

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

---

## 🔍 Proceso de trabajo

### 1. Carga de datos

* Importación del dataset
* Inspección inicial (head, info, describe)

### 2. Limpieza de datos

* Tratamiento de valores nulos
* Eliminación de duplicados
* Corrección de tipos de datos

### 3. Análisis exploratorio

* Análisis univariante
* Análisis bivariante
* Correlaciones

### 4. Visualización

* Gráficos de distribución
* Boxplots
* Heatmaps
* Relación entre variables

---

## 📈 Principales insights

*(Aquí puedes añadir tus conclusiones reales, por ejemplo:)*

* Variables con mayor impacto en el dataset
* Tendencias detectadas
* Posibles relaciones entre variables
